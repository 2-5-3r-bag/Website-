## Ажиллуулах

Төслийн хавтсанд PowerShell нээгээд:

```powershell
python -m http.server 8000
```

Дараа нь `http://localhost:8000` хаягийг нээнэ. Build алхам болон нэмэлт сан шаардлагагүй.

- `index.html` — нүүр, текстэн лого, онцлох сүрчиг
- `brands.html`, `emegtei.html`, `eregtei.html` — статик бүтээгдэхүүний каталогууд
- `product.html` — бүтээгдэхүүний нэр бүр рүү үсрэх дэлгэрэнгүй жагсаалт
- `salbar.html`, `tuhai.html` — салбар болон дэлгүүрийн тухай
- `sags.html`, `checkout.html`, `login.html`, `profile.html` — статик тайлбарын хуудсууд

ZENith Beauty бол зөвхөн HTML болон CSS ашигласан статик сүрчигний каталог юм. Хуудаснууд JavaScript ашиглахгүй.

## Ажиллуулах

index.html файлыг хөтөч дээр нээх, эсвэл төслийн хавтсанд python -m http.server 8000 ажиллуулаад http://localhost:8000 хаягаар орно.

## Хуудаснууд

- index.html — нүүр хуудас
- brands.html, emegtei.html, eregtei.html — каталог, хэмжээний үнэ
- product.html — бүх сүрчигний хэмжээ, үнийн жагсаалт
- salbar.html, tuhai.html — салбар болон дэлгүүрийн мэдээлэл
- facebook.html — Facebook хуудсанд зураг, холбоосоор нэвтрэх
- feedback.html — талархал, гомдол, саналын статик маягт
- checkout.html, profile.html — статик тайлбарын хуудсууд

## Үнийн мэдээлэл

Small: 30 мл; Medium: 60–75 мл; Large: 90–100 мл. Бодит савлагааны хэмжээг боломжтой үед хамт харуулав. Баталгаатай үнэ олдоогүй хэмжээг “—” гэж тэмдэглэв. Үнэ ам.доллараар бөгөөд АНУ-ын албан ёсны болон зарим хямдралтай онлайн дэлгүүрийн эх сурвалж холилдсон; Монгол дахь үнэ, татвар, хүргэлтийг тусгаагүй.
