# ZENith Beauty

Компьютерийн дэлгэцэд зориулсан, зөвхөн HTML болон CSS-ээр бүтээсэн статик сүрчигний каталог.

## Ажиллуулах

Төслийн хавтсанд PowerShell нээгээд:

```powershell
python -m http.server 8000
```

Дараа нь `http://localhost:8000` хаягийг нээнэ. Build алхам болон нэмэлт сан шаардлагагүй.

## Хуудаснууд

- `index.html` — нүүр, текстэн лого, онцлох сүрчиг
- `brands.html`, `emegtei.html`, `eregtei.html` — статик бүтээгдэхүүний каталогууд
- `product.html` — бүтээгдэхүүний нэр бүр рүү үсрэх дэлгэрэнгүй жагсаалт
- `salbar.html`, `tuhai.html` — салбар болон дэлгүүрийн тухай
- `sags.html`, `checkout.html`, `login.html`, `profile.html` — статик тайлбарын хуудсууд

JavaScript ашигладаггүй тул сагс, нэвтрэлт, хайлт болон захиалга өгөгдөл хадгалахгүй. Бүтээгдэхүүний үнэ, хэмжээ, үнэрийн ноот жагсаалтад байхгүй учир “Үнэ лавлах” гэж харуулна.
